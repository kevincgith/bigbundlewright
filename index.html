🔒 Your documents never leave this device.
How?

Big Bundle Wright is a plain web page. Your browser reads the files you add and builds the bundle with code running on this computer. Nothing is uploaded: there is no server processing, no analytics, no cookies and no third-party content, and the page's security policy blocks connections to other sites. Closing the tab discards everything unless you save a project file or tick "Remember project details".
