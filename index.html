Court bundles fit for a 大狀

Indexed, paginated top right, hyperlinked and split into volumes, following Practice Direction 5.6.

Your documents never leave this device.
How?

Big Bundle Wright is a plain web page. Your browser reads the files you add and builds the bundle with code running on this computer. Nothing is uploaded: there is no server processing, no analytics, no cookies and no third-party content, and the page is set up so it cannot send anything elsewhere. Closing the page clears everything unless you press "Save work" or tick "Remember my work in this browser".

What do bundle, volume, issue and the other words mean?

Bundle
The set of documents for the trial judge: in date order, numbered page by page, with an index at the front. PD 5.6 calls it the agreed bundle. Big Bundle Wright makes it as PDF files you can lodge, print or serve.
Volume (Bundle A, Bundle B)
One file of the bundle. PD 5.6 para 5 says a file should never hold more than 250 pages, so a large bundle is split into Bundle A, Bundle B and so on, each with its own index. A document is only split if it is over 250 pages on its own. The master index lists every document across all volumes.
Index and status front sheet
The index lists each document with its number, date, description, status and pages, and each entry is a link to its first page. The front sheet, before the index, states which documents fall into each status category (PD 5.6 para 3).
Status
What the parties have agreed about a document: (1) authentic, (2) agreed for inclusion in the bundle only, or (3) also agreed as evidence of its contents. You choose it for each document in the list.
Core bundle
A short bundle of the documents central to the dispute, needed when the agreed bundle is over 100 pages (PD 5.6 para 2). Tick "Core" for those documents. Its pages are numbered C1, C2 and its index shows where each document is in the main bundle.
Transcript bundle
Transcripts of evidence or judgments go in their own bundle (PD 5.6 paras 4 and 5), numbered T1, T2. Set a document's type to "Transcript" and it goes there automatically.
Your work
The list you build on this page: the case details, the documents in order with their dates, descriptions and statuses, and the settings. It stays on this page while you work.
Saved work
"Save work" puts your work in a small file so you can come back later. The file does not contain the documents, only the list, the settings and a note of each document so it can be recognised. To carry on, press "Open saved work", choose the file, then add the same PDFs again; renamed copies are fine. Each bundle download also includes it.
Issue
Use "Build and issue" when the bundle is final, for example when you lodge or serve it. Issuing locks every page number. From then on, adding a document never renumbers anything already in the bundle, so references to "page 88" stay right. Save your work after issuing. "Unlock" undoes this, but the next build then renumbers the whole bundle, so only do it if you will issue, lodge and serve everything again.
Additional documents (88-1, 88-2)
A document added after issue goes in after a page you choose and takes numbers like 88-1, 88-2, 88-3 (PD 5.6 para 1), so page 89 stays page 89. Until you issue again, these new numbers are provisional.
Typed copy
A typed version of a page that is hard to read, placed straight after it (PD 5.6 para 6).
Cover page
An optional page of your own, such as a firm cover sheet, placed before the index. It is not numbered.
Lodging deadline
Agreed bundles must be lodged at least 72 hours before the hearing, not counting Saturdays, Sundays and general holidays (PD 5.6 para 8). Enter the hearing date and the page works out the last day.
